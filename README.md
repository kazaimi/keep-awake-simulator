# KeepAwake - 沉浸式任务模拟与防息屏/防锁屏系统

专为保持电脑常亮并营造“正在进行核心关键任务”而设计的小程序。

---

## 🌟 核心特性

### 1. 内核级 + 软硬件双保险防锁屏
- **Windows 原生内核 API**：通过 `SetThreadExecutionState` 声明持续运行与常亮状态（`ES_CONTINUOUS | ES_SYSTEM_REQUIRED | ES_DISPLAY_REQUIRED`）。
- **零感知无副作用微活动**：后台每 25 秒触发极微小的系统输入事件，完美规避企业 IT 组策略（GPO）对于无操作自动锁定桌面的强制机制。
- **浏览器 Screen Wake Lock API**：前端页面内置双保险屏幕锁，无需安装驱动或管理员权限。

### 2. 六套超逼真的“高负荷”忙碌工作模式
1. **大语言模型分布式预训练 (AI LLM Pretraining)**
   - 8 卡 GPU 集群算力仪表板（显存占用 ~96%、功耗 380W、核心温度实时波动）。
   - 动态实时 Loss 衰减发光折线图（平滑指数衰减 + 微小噪声波动）。
   - Tensor 训练日志流（ZeRO-Stage-3、FlashAttention-2、梯度同步、Step 步进与 ETA 预估）。
2. **云原生 DevOps & 微服务构建发布 (Cloud-Native Pipeline)**
   - 多阶段 Docker 构建、Rust/Go 编译流、依赖树分析。
   - 80 节点并发测试矩阵状态网格实时刷新（4000+ 测试用例自动累加跑动）。
   - Kubernetes 集群 Pod 调度与部署状态流水。
3. **全球网络安全攻防与态势感知 (Cyber Threat Hunter)**
   - 360° 实时动态雷达扫掠（Canvas 动画与方位角锁定追踪）。
   - 实时 Hex 内存 Dump 字节流解析。
   - WAF / IPS 实时入侵与威胁防御阻断日志。
4. **高频量化交易算法与撮合回测 (Quant Trading Engine)**
   - 40 根实时跳动蜡烛 K 线图 + MA7/MA25 均线与成交量柱状图。
   - 盘口买卖订单簿深度与微秒级高频撮合成交流水。
5. **微软 Word / Office 365 深度方案撰写 (Word Office Suite)**
   - 100% 像素级还原的经典 Office 蓝顶栏（带自动保存开关、OneDrive 状态、搜索框、共享、用户头像）。
   - 完整的 Ribbon 功能区选项卡（开始、插入、绘图、布局、样式库、字号字体、对齐等高拟真卡片）。
   - 水平标尺（刻度 1~38、缩进游标滑块）与标准 A4 纯白纸张投影排版。
   - **拟真自然打字机 (Realistic Typist)**：逐字敲出严肃企业公文企划，包含思考停顿、手误打错字退格重敲、闪烁打字光标、自动换行与视口平滑跟随；字数实时统计、云端保存状态切换。
   - **一键暂停/继续打字**：支持快捷键 **`X`** 或 **`Ctrl+P`**，以及顶栏/底栏显式按钮，随时一键暂停/恢复出字。
   - **真实可编辑支持**：页面为真实 `contenteditable`，用户可随时在纸上亲自输入修改；停手 3.5 秒后自动打字机继续自然书写。
6. **OpenAI o1-preview 深度思考大模型 (ChatGPT Reasoning)**
   - 100% 原生深色风格 ChatGPT 界面（左侧深黑历史会话侧边栏 + 底部 Alex Xu Pro 会话账户卡片）。
   - 用户提问气泡：全球分布式强一致性千万级 TPS 撮合引擎架构难题。
   - **标志性折叠深度思考框 (Thought Box)**：
     - 旋转极光 Spinner 与实时递增计时器（`Thinking for 46 seconds...`）；
     - **动态展开的思维链条 (Chain of Thought - CoT)**：不断展开流出高阶数学与分布式推导步骤；

   - 经典圆角胶囊输入框、附件图标、免责声明。

### 3. 一键伪装老板键 (Boss Key)
- 按 **`空格键` (Space)** 或点击控制栏的「老板键」：
  - 瞬间切换为严肃逼真的 **“2026年企业 Q3 业务战略复盘与各事业部执行效能追踪报表”**（仿企业 BI / ERP 浅灰白专业表格与折线走势图、待办清单）。
  - 再次按 **`空格键`** 立即无缝切回极客任务界面。

### 4. 极致交互与细节
- **自感应滑出顶栏**：平时完全自动隐藏，鼠标移至屏幕最顶部时优雅滑出；支持点击“钉住”图标固定显示。
- **全屏沉浸**：快捷键 **`F11`** 或**双击屏幕空白处**即可一键进入沉浸式全屏。
- **调速齿轮**：支持 1x (Normal)、2x (Fast)、5x (Hyper) 三档动态滚屏与运算步进速度切换。
- **声效模拟**：内置纯原生 Web Audio 机械键盘打字与数据滴答声（默认静音，可一键开启，无外部音频文件）。
- **智能滚屏**：向上滚动滚轮查看历史日志时自动暂停滚屏，滚回底部自动恢复自动滚动。

## 🚀 启动方法

### 方式一：双击一键启动（推荐）
- 直接双击目录下的 **`启动.bat`**（或 **`run.bat`**）。
- 脚本会自动检测 Python 环境，以内核级防锁屏 + Edge 独立 App 窗口无边框启动。

### 方式二：命令行启动
```bash
python main.py
```

### 方式三：极简免环境模式（离线直接双击）
- 在没有 Python 的电脑上，直接用任何现代浏览器（Edge / Chrome / Firefox）双击打开 **`index.html`**，同样拥有前端 WakeLock 保持亮屏与全部动态效果！

## ⌨️ 快捷键清单

| 按键 | 功能说明 |
| :--- | :--- |
| **`Space` (空格键)** | **老板键**：瞬间切换/恢复严肃办公报表 |
| **`F11`** 或 **双击空白处** | **全屏模式**：切换真全屏沉浸显示 |
| **`1` ~ `6`** | 快速切换 6 大模式（按 `5` 切换 Word，按 `6` 切换 ChatGPT） |
| **`Alt + 1~6`** | 即使在 Word 正文编辑时也可强制切换任务模式 |
| **`X`** 或 **`Ctrl+P`** | **Word 模式专属**：一键暂停 / 恢复自动打字 |
| **`S`** | 切换 1x / 2x / 5x 日志与运算速度 |
| **`M`** | 静音 / 开启机械打字声音效 |
| **`ESC`** | 退出全屏 / 关闭弹窗 / 编辑失焦 |
